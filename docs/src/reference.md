## Privacy and vulnerability reports

Read [SECURITY.md](https://github.com/Busnes-app/KyNotes-server/blob/master/SECURITY.md) for this product's security model,
known limits and private reporting route. Follow that policy for suspected vulnerabilities.
Do not publish credentials or private data in a public issue.

## Versions

Use the [release record](https://github.com/Busnes-app/KyNotes-server/releases) and, where present, the repository changelog.
A successful build is not proof of a published or qualified release.
