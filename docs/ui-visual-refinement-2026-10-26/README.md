## Changes

- **One primary per view:**
  - The empty editor's "Create a note" stays the filled accent action.
  - The new-page "+", the header note Save and every key, recovery or team banner action are outlined secondary buttons (`.secondary`).
  - The commit toast is a neutral panel. It was orange because the global accent rule caught that `<button>`.
- **Decoration:**
  - The empty editor's sparkle glyph is removed.
  - Sidebar glyph icons use the ink colour, not the accent.
  - The header sync status is sans, not mono.
- **Labels:** the sidebar and editor section labels (Focus, Notebooks, Team notebooks, Account, Resurfacing, Knowledge graph) are sentence case with even spacing. The notebook action rows are 40px rows.
- **Callouts:** the recovery, key and team banners share one neutral panel with a warning rule instead of the pink fill. Their text, roles (`status`/`alert`) and actions are unchanged.
- **Phone:** "Notebooks and account" is a quiet 40px bar with the same name, `aria-expanded` behaviour and full sidebar (`e2e/mobile-navigation.e2e.ts`).
- Shared catalog, colours, fonts, storage keys, CSP and Settings › Appearance placement are unchanged.

## Remaining limits

- The Settings sub-navigation links to sections on one scrolling page, so it marks no current item. A scroll-tracking marker would be new behaviour and was left out.
- The account region still shows no sign-out; Lock sits in the header, as before.
- Canvas page text renders in the editor's own font, not Space Grotesk; the editor was not changed.
- "New notebook" sits directly under the Team notebooks label when there are no teams, an existing order.
- Note rows keep a wide left indent.
- Idle radios in dark mode render as faint discs: a shared ky-ui picker style.

## Reproduce

From the repository root: `node docs/ui-visual-refinement-2026-10-26/capture.mjs <prefix> [surface,...]` or `... --verify <prefix>`. The driver builds the server into a temporary directory on loopback port 18091 and removes it afterwards.
