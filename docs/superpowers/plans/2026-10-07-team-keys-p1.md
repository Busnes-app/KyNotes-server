# Team Keys Phase 1 (Crypto Primitives and Identity) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every account gains a per-user X25519 identity whose private key is wrapped under a password-derived `userKEK` the server never sees. This phase also ships the envelope primitives later phases use. No content changes: every note, attachment and comment stays keyed from `authSecret` exactly as today.

**Architecture:** The browser derives `authSecret` and `userKEK` from one PBKDF2 pass using two HKDF labels. On a password login or `/setup` it silently creates or loads the identity through `GET`/`PUT /api/v1/me/identity`. The server stores the identity as a `devices` row with `platform='identity'` and an unusable `secret_hash`, plus a `user_identities` row that holds the opaque wrapped private key. Identity rows never authenticate, never appear in device lists, revocation or selection, and are excluded from the current save gate. Password change re-wraps the identity in the same transaction. Recovery and admin reset delete it. A Go reference in `internal/teamkeys` pins the byte formats through checked-in vectors that vitest replays.

**Tech Stack:** Go 1.26 (`golang.org/x/crypto` already allowlisted, used only in tests here), SQLite migrations, TypeScript/React, vitest, `@noble/curves@2.4.0` and `@noble/ciphers@2.4.0` (MIT, pinned exact).

**Spec:** `docs/superpowers/specs/2026-10-07-team-keys-design.md` §0, §1, §5, §6, §7-P1.

**Prototype evidence (2026-10-07, scratch copies outside the repo):** every code block below was compiled and run. Go: `go vet ./...` clean, `go test -race ./...` green except `cmd/kynotes-server`, whose restore test refuses a data dir under `/tmp` (the scratch location, not this change). Web: `tsc --noEmit`, all 159 vitest tests and `vite build` pass. All 11 server guards were mutation-checked: removing any one of them fails a named test. The Go vectors and the TypeScript implementation agree byte for byte, and the RFC vectors pass.

## Global Constraints

| Item | Exact value |
|---|---|
| Envelope `alg` (wire, unchanged frozen allowlist) | `x25519-hkdf-sha256-chacha20poly1305` |
| Envelope bytes | `0x01 \| ephPub(32) \| nonce(12) \| ChaCha20-Poly1305(key, nonce, CK(32), aad)` = **93 bytes** (ct 32 + tag 16). Offsets: version `[0]`, ephPub `[1,33)`, nonce `[33,45)`, sealed `[45,93)` |
| Envelope key | `HKDF-SHA256(ikm = X25519(ephPriv, recipientPub), salt = ephPub \|\| recipientPub, info = "kynotes/envelope/v1", L = 32)` |
| Envelope AAD | `"kynotes/envelope/v1" \|\| containerID \|\| u32be(keyGeneration) \|\| recipientDeviceID`. No separators: both IDs must match `^(cnt\|dev)_[0-9a-hjkmnp-tv-z]{26}$` (fixed 30 bytes, `internal/ids` alphabet), and `keyGeneration` is an integer in `[1, 2^32-1]`. Anything else throws before the AAD is built |
| Login derivation | `stretched = PBKDF2-SHA256(password, base64decode(loginSalt), iterations, 32)`. `authSecret = hex(HKDF(stretched, salt = empty, info = "kynotes/auth/v1", 32))` (frozen, unchanged). `userKEK = HKDF(stretched, salt = empty, info = "kynotes/user-kek/v1", 32)` (new, never sent) |
| Identity wrap `wrap_alg` | `aes-256-gcm` |
| Wrapped identity bytes | `nonce(12) \| AES-256-GCM(userKEK, nonce, privateKey(32), aad) \| tag(16)` = **60 bytes** |
| Identity AAD | `"kynotes/identity/v1" \|\| userID` (`userID` matches `^usr_[0-9a-hjkmnp-tv-z]{26}$`) |
| Identity keypair | X25519, raw 32-byte keys; the public key is standard base64 on the wire (same as the frozen device key) |
| Identity device row | `devices.platform = 'identity'`, `secret_hash = "identity:" + hex(32 random bytes)` (never the `sha256:` prefix device auth compares against), `fingerprint = hex(sha256(pub))` computed by the server, `sso_session_id = ''`, `label_ciphertext = x''` |
| Migration | `internal/storage/migrations/0021_identity_keys.sql`. The highest existing migration is 0019 on master, and no worktree (B, subpages, canvas, onenote, applysetup) adds 0021 |
| Routes | `GET /api/v1/me/identity` (session only, device credential rejected, `Cache-Control: no-store`, 404 `not_found` when absent). `PUT /api/v1/me/identity` (session, CSRF, `auth.RequireUserStepUp`; create-only, 409 `identity_exists` when one exists) |
| Password change | `POST /api/v1/auth/password` accepts `wrappedIdentityKey` (base64, 60 bytes). It is required exactly when an identity exists; otherwise the server answers 409 `identity_rewrap_required` and commits nothing |
| Randomness | Only `@noble/ciphers` `randomBytes` and `x25519.keygen()`, which throw without `crypto.getRandomValues`. Never `crypto.ts` `getRandomValues`, whose fallback is `Math.random` |
| Deps | `@noble/curves` `2.4.0` (depends only on `@noble/hashes` `2.4.0`) and `@noble/ciphers` `2.4.0` (no deps). All three are MIT and need Node ≥ 20.19 (repo CI uses Node 24) |

## Resolved ambiguities (record in the spec in Task 9)

1. **Migration 0021 holds only `user_identities` plus the one-identity index.** Spec §5 also lists `invitation_envelopes` and `object_versions.author_user_id` under 0021. Applied migrations are immutable (§1.13), and P1 needs neither table, so P2 adds them as `0022`.
2. **`PUT /me/identity` is create-only in P1.** Replacing an identity is destructive (it drops envelopes) and has no caller until P5. Create-only also makes the two-tab first-login race safe: the loser gets 409 `identity_exists`, re-reads, and adopts the winner.
3. **Step-up for ordinary users.** `auth.RequireStepUp` is admin-only, and the OIDC step-up grant is admin-only (`liveStepUpSession` requires `u.role='admin'`). This plan adds `auth.RequireUserStepUp`: any local session with `stepup_at` inside `StepUpWindow`, with SSO sessions refused. The client calls the existing `POST /auth/step-up` with the `authSecret` it just derived, then `PUT`. Side effect: a user's first login after P1 leaves a 10-minute step-up window on that session. It happens once per account and comes from a real proof of the password seconds earlier.
4. **The identity is created only after a successful local `login()` or `/setup`.** In the SSO fallback path (master password typed, local login failed) there is no local session to step up, so creation waits for the next password login.
5. **The identity private key is not persisted in IndexedDB in P1.** Nothing reads it until P3. That phase adds it to the keys vault next to its first reader, and "Forget this device" still clears it with a single delete. `storage.ts` is untouched.
6. **`/setup` stops sending the plaintext password.** `submitSetup` currently posts `password` together with `authSecret`. The server ignores it when `authSecret` is present, but that would let a malicious server derive the first admin's `userKEK`. The client now sends `undefined`.
7. **Recovery and admin reset delete the identity row.** Revoking it is not enough. The `devices` foreign keys cascade to `user_identities` and `key_envelopes`. `account.recovery` and `admin.user.password_reset` stay the audit records, and no content uses the identity yet.
8. **The P1 save gate must ignore identity rows.** Without that, the first identity row would make every save return 409 `key rotation incomplete`. The three copies of the gate SQL become one `missingEnvelopesSQL` constant, which P2 replaces.

## Review Focus (likely failure modes and their pinning tests)

1. **An identity row authenticates as a device, or a phone takes one over.** Device auth must filter `platform<>'identity'` independently of the unusable hash. Pinned by: `TestIdentityRowCannotAuthenticateAsDevice`, which plants a valid `sha256:` hash on the row and still expects 401. `/devices/register` must refuse `platform:"identity"` and must not re-pair onto the identity row when a phone presents the identity's public key. Pinned by: `TestRegisterCannotClaimIdentity`.
2. **A password change orphans the identity.** An old cached bundle, a missing field or a non-atomic write must not commit a new password while leaving the identity wrapped under the old `userKEK`. Pinned by: `TestPasswordChangeRewrapsIdentityAtomically` (409 without the field, salt unchanged after a refusal, salt and wrapped key committed together) and vitest `re-wraps the same key for a password change`.
3. **The AAD is mismatched or ambiguous.** The Go and TS byte layouts must not drift; the envelope must not be openable in a different container, generation or recipient; and malformed IDs must not change the AAD length. Pinned by: `TestEnvelopeVectors` (Go, file must match generator), vitest `seals and opens envelopes exactly like Go`, `refuses an envelope replayed into another container, generation or recipient` and `rejects malformed IDs and generations before building AAD`.
4. **Key material leaks.** The private key or `userKEK` must not appear in a request body, the vault, logs or a cacheable response. Pinned by: vitest `creates once on first sign-in and uploads only wrapped material` (hex and base64 of both secrets are absent from the PUT body); `TestIdentityGetReturnsWrappedKeyToSessionOnly` (`no-store`, device credential refused); `git grep -n identity web/src/storage.ts` must print nothing (Task 8 Step 6); the existing `TestNoPrivateKeyOrTokenMaterialInAnyTable` sweeps the new table automatically.
5. **Old clients and the save gate.** Pre-P1 phones list or revoke devices and must never see identity rows. A content save must not hit the old gate because of identity rows. Pinned by: `TestIdentityRowHiddenFromDeviceRoutes` (list, revoke, selection GET and PUT all 404 or omit it), `TestIdentityDoesNotBlockSaves` and the existing device contract suite. No test covers the gate today: the spec's `TestNewContentRefusedUntilRotationEnvelopesExist` does not exist yet, and P2 must write it, not "update" it.

Also check: `ensureIdentity` never PUTs when the existing identity fails to open (`never replaces an identity it cannot open`), and a server-substituted public key is refused (`refuses a server-substituted public key`).

```go
	RecipientPrivateKey string `json:"recipientPrivateKey"`
	RecipientPublicKey  string `json:"recipientPublicKey"`

	ContentKey          string `json:"contentKey"`
	Envelope            string `json:"envelope"`
}

type vectors struct {

	Identity  []identityVector `json:"identity"`

func unhex(t *testing.T, s string) []byte {
	t.Helper()
	b, err := hex.DecodeString(s)
	if err != nil {
		t.Fatal(err)
	}
	return b
}

func hkdf32(t *testing.T, secret, salt []byte, info string) []byte {
	t.Helper()
	out := make([]byte, 32)
	if _, err := hkdf.New(sha256.New, secret, salt, []byte(info)).Read(out); err != nil {
		t.Fatal(err)
	}
	return out
}

func x25519(t *testing.T, scalar, point []byte) []byte {
	t.Helper()
	out, err := curve25519.X25519(scalar, point)
	if err != nil {
		t.Fatal(err)
	}
	return out
}

func login(t *testing.T, password, salt string, iterations int) loginVector {
	raw, err := base64.StdEncoding.DecodeString(salt)
	if err != nil {
		t.Fatal(err)
	}
	stretched := pbkdf2.Key([]byte(password), raw, iterations, 32, sha256.New)
	return loginVector{password, salt, iterations, hex.EncodeToString(hkdf32(t, stretched, nil, "kynotes/auth/v1")), hex.EncodeToString(hkdf32(t, stretched, nil, "kynotes/user-kek/v1"))}
}

func identity(t *testing.T, userID, kek, priv, nonce string) identityVector {
	block, err := aes.NewCipher(unhex(t, kek))
	if err != nil {
		t.Fatal(err)
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		t.Fatal(err)
	}
	n := unhex(t, nonce)
	wrapped := gcm.Seal(bytes.Clone(n), n, unhex(t, priv), append([]byte("kynotes/identity/v1"), userID...))
	pub := x25519(t, unhex(t, priv), curve25519.Basepoint)
	return identityVector{userID, kek, priv, hex.EncodeToString(pub), nonce, hex.EncodeToString(wrapped)}
}

func envelope(t *testing.T, containerID string, generation uint32, deviceID, recipientPriv, ephPriv, nonce, contentKey string) envelopeVector {
	recipientPub := x25519(t, unhex(t, recipientPriv), curve25519.Basepoint)
	ephPub := x25519(t, unhex(t, ephPriv), curve25519.Basepoint)
	shared := x25519(t, unhex(t, ephPriv), recipientPub)
	key := hkdf32(t, shared, append(bytes.Clone(ephPub), recipientPub...), "kynotes/envelope/v1")
	aad := append([]byte("kynotes/envelope/v1"), containerID...)
	aad = binary.BigEndian.AppendUint32(aad, generation)
	aad = append(aad, deviceID...)
	aead, err := chacha20poly1305.New(key)
	if err != nil {
		t.Fatal(err)
	}
	n := unhex(t, nonce)
	env := append([]byte{0x01}, ephPub...)
	env = append(env, n...)
	env = aead.Seal(env, n, unhex(t, contentKey), aad)
	if len(env) != 93 {
		t.Fatalf("envelope is %d bytes, want 93", len(env))
	}
	// The recipient side must open what the sender side sealed.
	back := hkdf32(t, x25519(t, unhex(t, recipientPriv), ephPub), append(bytes.Clone(ephPub), recipientPub...), "kynotes/envelope/v1")
	open, _ := chacha20poly1305.New(back)
	if pt, err := open.Open(nil, n, env[45:], aad); err != nil || hex.EncodeToString(pt) != contentKey {
		t.Fatalf("round trip failed: %v", err)
	}
	return envelopeVector{containerID, generation, deviceID, recipientPriv, hex.EncodeToString(recipientPub), ephPriv, nonce, contentKey, hex.EncodeToString(env)}
}
```

```ts
import { gcm } from "@noble/ciphers/aes.js";
import { chacha20poly1305 } from "@noble/ciphers/chacha.js";
import { randomBytes } from "@noble/ciphers/utils.js";
import { x25519 } from "@noble/curves/ed25519.js";
import { hkdfSha256 } from "./fallbackCrypto";

export const ENVELOPE_ALG = "x25519-hkdf-sha256-chacha20poly1305";
export const IDENTITY_WRAP_ALG = "aes-256-gcm";
export const ENVELOPE_BYTES = 93;
export const WRAPPED_IDENTITY_BYTES = 60;
const ENVELOPE_LABEL = "kynotes/envelope/v1";
const IDENTITY_LABEL = "kynotes/identity/v1";
const ENVELOPE_VERSION = 0x01;
const ID = /^(cnt|dev|usr)_[0-9a-hjkmnp-tv-z]{26}$/;
const encoder = new TextEncoder();

export type Identity = { publicKey: Uint8Array; privateKey: Uint8Array };

function idBytes(prefix: "cnt" | "dev" | "usr", value: string): Uint8Array {
  if (!value.startsWith(`${prefix}_`) || !ID.test(value)) throw new Error(`invalid ${prefix} id`);
  return encoder.encode(value);
}

function concat(...parts: Uint8Array[]): Uint8Array {
  const out = new Uint8Array(parts.reduce((n, p) => n + p.length, 0));
  let at = 0;
  for (const p of parts) { out.set(p, at); at += p.length; }
  return out;
}

export function generateIdentity(): Identity {
  const { secretKey, publicKey } = x25519.keygen();
  return { privateKey: secretKey, publicKey };
}

export function envelopeAAD(containerID: string, keyGeneration: number, recipientDeviceID: string): Uint8Array {
  if (!Number.isInteger(keyGeneration) || keyGeneration < 1 || keyGeneration > 0xffffffff) throw new Error("invalid key generation");
  const generation = new Uint8Array(4);
  new DataView(generation.buffer).setUint32(0, keyGeneration);
  return concat(encoder.encode(ENVELOPE_LABEL), idBytes("cnt", containerID), generation, idBytes("dev", recipientDeviceID));
}

function envelopeKey(ephemeralPrivate: Uint8Array, peerPublic: Uint8Array, ephemeralPublic: Uint8Array, recipientPublic: Uint8Array): Uint8Array {
  const shared = x25519.getSharedSecret(ephemeralPrivate, peerPublic);
  return hkdfSha256(shared, 32, concat(ephemeralPublic, recipientPublic), encoder.encode(ENVELOPE_LABEL));
}

/** `ephemeralPrivateKey` and `nonce` are injectable for fixed test vectors only. */
export function wrapEnvelope(
  contentKey: Uint8Array, recipientPublicKey: Uint8Array, containerID: string, keyGeneration: number, recipientDeviceID: string,
  ephemeralPrivateKey: Uint8Array = x25519.utils.randomSecretKey(), nonce: Uint8Array = randomBytes(12),
): Uint8Array {
  if (contentKey.length !== 32 || recipientPublicKey.length !== 32 || nonce.length !== 12) throw new Error("invalid envelope input");
  const aad = envelopeAAD(containerID, keyGeneration, recipientDeviceID);
  const ephemeralPublic = x25519.getPublicKey(ephemeralPrivateKey);
  const key = envelopeKey(ephemeralPrivateKey, recipientPublicKey, ephemeralPublic, recipientPublicKey);
  const sealed = chacha20poly1305(key, nonce, aad).encrypt(contentKey);
  return concat(Uint8Array.of(ENVELOPE_VERSION), ephemeralPublic, nonce, sealed);
}

export function unwrapEnvelope(envelope: Uint8Array, recipientPrivateKey: Uint8Array, containerID: string, keyGeneration: number, recipientDeviceID: string): Uint8Array {
  if (envelope.length !== ENVELOPE_BYTES || envelope[0] !== ENVELOPE_VERSION) throw new Error("unsupported envelope");
  const aad = envelopeAAD(containerID, keyGeneration, recipientDeviceID);
  const ephemeralPublic = envelope.subarray(1, 33);
  const nonce = envelope.subarray(33, 45);
  const recipientPublic = x25519.getPublicKey(recipientPrivateKey);
  const key = envelopeKey(recipientPrivateKey, ephemeralPublic, ephemeralPublic, recipientPublic);
  return chacha20poly1305(key, nonce, aad).decrypt(envelope.subarray(45));
}

function identityAAD(userID: string): Uint8Array {
  return concat(encoder.encode(IDENTITY_LABEL), idBytes("usr", userID));
}

/** `nonce` is injectable for fixed test vectors only. */
export function wrapIdentity(userKEK: Uint8Array, privateKey: Uint8Array, userID: string, nonce: Uint8Array = randomBytes(12)): Uint8Array {
  if (userKEK.length !== 32 || privateKey.length !== 32 || nonce.length !== 12) throw new Error("invalid identity input");
  return concat(nonce, gcm(userKEK, nonce, identityAAD(userID)).encrypt(privateKey));
}

export function unwrapIdentity(userKEK: Uint8Array, wrapped: Uint8Array, userID: string): Identity {
  if (userKEK.length !== 32 || wrapped.length !== WRAPPED_IDENTITY_BYTES) throw new Error("invalid wrapped identity");
  const privateKey = gcm(userKEK, wrapped.subarray(0, 12), identityAAD(userID)).decrypt(wrapped.subarray(12));
  return { privateKey, publicKey: x25519.getPublicKey(privateKey) };
}
```

```ts
import { base64, fromBase64, type LoginKeys } from "./crypto";
import { generateIdentity, IDENTITY_WRAP_ALG, unwrapIdentity, wrapIdentity, type Identity } from "./teamKeys";

export type IdentityRecord = { deviceId: string; publicKey: string; fingerprint: string; wrapAlg: string; wrappedPrivateKey: string };
export type IdentityUpload = { publicKey: string; wrapAlg: string; wrappedPrivateKey: string };
export type IdentityAPI = {
  myIdentity: () => Promise<IdentityRecord | undefined>;
  putMyIdentity: (input: IdentityUpload) => Promise<unknown>;
  stepUp: (authSecret: string) => Promise<void>;
};

function sameBytes(a: Uint8Array, b: Uint8Array): boolean {
  return a.length === b.length && a.every((value, i) => value === b[i]);
}

/** Unlocks the server copy and refuses a public key the private key does not produce. */
export function openIdentity(record: IdentityRecord, userKEK: Uint8Array, userID: string): Identity {
  if (record.wrapAlg !== IDENTITY_WRAP_ALG) throw new Error("unsupported identity wrap");
  const identity = unwrapIdentity(userKEK, fromBase64(record.wrappedPrivateKey), userID);
  if (!sameBytes(identity.publicKey, fromBase64(record.publicKey))) throw new Error("identity public key mismatch");
  return identity;
}

/** Loads the identity, creating it on first sign-in. Never replaces one it cannot open. */
export async function ensureIdentity(api: IdentityAPI, userID: string, keys: LoginKeys): Promise<Identity> {
  const record = await api.myIdentity();
  if (record) return openIdentity(record, keys.userKEK, userID);
  const identity = generateIdentity();
  const upload = { publicKey: base64(identity.publicKey), wrapAlg: IDENTITY_WRAP_ALG, wrappedPrivateKey: base64(wrapIdentity(keys.userKEK, identity.privateKey, userID)) };
  await api.stepUp(keys.authSecret);
  try {
    await api.putMyIdentity(upload);
    return identity;
  } catch (error) {
    // Another tab won the create race: use its identity, not ours.
    const winner = (error as { code?: string }).code === "identity_exists" ? await api.myIdentity() : undefined;
    if (!winner) throw error;
    return openIdentity(winner, keys.userKEK, userID);
  }
}

/** The same private key under the new userKEK, or undefined when no identity exists yet. */
export async function rewrapIdentity(api: Pick<IdentityAPI, "myIdentity">, userID: string, oldKEK: Uint8Array, newKEK: Uint8Array): Promise<{ identity: Identity; wrappedIdentityKey: string } | undefined> {
  const record = await api.myIdentity();
  if (!record) return undefined;
  const identity = openIdentity(record, oldKEK, userID);
  return { identity, wrappedIdentityKey: base64(wrapIdentity(newKEK, identity.privateKey, userID)) };
}
```
